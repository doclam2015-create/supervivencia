# Supervivencia

App web instalable (PWA) que funciona **sin conexión** en iPhone y iPad.

- **Manual visual**: 137 técnicas en 16 capítulos (nudos, herramientas naturales, fuego, refugio, agua, alimentos comestibles y tóxicos, primeros auxilios, orientación, señales, clima, entornos extremos, animales, higiene, desplazamiento) con 64 dibujos.
- **Buscador** con sinónimos y resaltado; **técnicas propias** con foto (se guardan en el dispositivo).
- **Silbato** por frecuencias (mantén presionado o fija), patrones 3 pitidos / SOS / alpina, y tonos para ahuyentar animales con lo que dice la evidencia.
- **SOS**: destello de pantalla, estroboscopio, luz roja, Morse, mensaje con coordenadas, ficha médica.
- **Brújula y GPS**: rumbo, coordenadas, UTM, altitud, puntos guardados con distancia y dirección, inclinómetro.

## Instalar
1. Abre la página en **Safari**.
2. Compartir → **Añadir a pantalla de inicio**.
3. Ábrela una vez con conexión: desde ahí funciona sin internet y no vence.
